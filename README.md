# RideSri – Tourist Bike Rental System

## About the Project
RideSri is a web-based Tourist Bike Rental System designed to help tourists easily find and rent bikes for their journeys in Sri Lanka.

## Features

### Tourist
- User Registration and Login
- Browse Available Bikes
- Book Bikes
- Demo Online Payment
- View Booking Details
- Cancel Pending Bookings

### Vehicle Owner
- Add New Bikes
- Edit Bike Details
- Delete Bikes
- View Rental Requests
- Confirm or Reject Bookings

### Admin
- Manage Users
- Manage Bikes
- Manage Bookings
- Manage Payments
- Update Booking Status

## Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: Python Flask
- Database: MySQL
- Database Management: phpMyAdmin / XAMPP

## Installation and Setup

1. Clone or download this repository.
2. Install the required Python packages.
3. Start Apache and MySQL using XAMPP.
4. Create the MySQL database `ridesri_db`.
5. Import the database SQL file.
6. Run the Flask application:

```bash
python app.py
```

7. Open your browser and visit:

```text
http://127.0.0.1:5000/
```

## Project Purpose
This project was developed as an academic project to demonstrate web application development, database management, and role-based system functionality.

## Note
The payment feature is a demonstration only. It does not process real financial transactions.
